# 🇬🇳 Quiz Interactif Histoire de la Guinée (Kahoot-like)

Système de quiz en temps réel avec WebSocket, Vue 3 et Node.js.

## Déploiement Gratuit en 2 minutes

### Option 1 : Render.com (Recommandé)
1. Créez un compte gratuit sur [render.com](https://render.com).
2. Cliquez sur **New +** -> **Web Service**.
3. Liez votre dépôt GitHub (ou connectez ce dossier).
4. Paramètres :
   - **Environment** : `Node`
   - **Build Command** : `npm install`
   - **Start Command** : `npm start`
5. Cliquez sur **Deploy Web Service**.
6. Vous obtenez une URL HTTPS publique (ex: `https://mon-quiz-guinee.onrender.com`). Le QR code s'adaptera automatiquement !

### Option 2 : Railway.app
1. Créez un compte sur [railway.app](https://railway.app).
2. Cliquez sur **New Project** -> **Deploy from GitHub repo**.
3. Railway détecte Node.js automatiquement et génère votre URL publique.
